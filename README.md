# jusenho

Carson's application to join dorm Jusenho. Live: https://keeonho.github.io/jusenho/

- `index.html` the whole site (GSAP ScrollTrigger + Lenis + three.js from CDN)
- `img/` black and white photos, pencil-sketch frames, and `keonho-reel.mp4`
- `reel/` the Remotion source for the Keonho stop-motion clip (`npm i && npx remotion render KeonhoReel`)

Member photos: Wikimedia Commons (CORTIS category) and public fan/press profile pages.
